# Publishing

Skills that turn analysis results into shareable output. Downstream of [analysis](../analysis/README.md) the same way analysis is downstream of [ingestion](../ingestion/README.md) — reports in, platform-native content out.

## Model-invoked

- **[report-card](./report-card/SKILL.md)** — Render a finished report as one self-contained HTML page: score hero, verdict filter chips, claims as cards on a phone, clean print-to-PDF. Stdlib only, no install step.
- **[share](./share/SKILL.md)** — Format a BS report as ready-to-paste posts for X (thread/single), LinkedIn, Facebook, Reddit, Hacker News, or a newsletter issue — plus a neo-brutalist image carousel (1080×1350 PNGs + PDF for LinkedIn document posts).
